How it is generated #

This site is generated automatically from the band data (YAML) and the research documents in the private repository ta1rjv/Turkiye-HAMBandPlan. Every number on the band pages is read from the same data files; it is never copied by hand into Markdown pages. The spectrum charts are static SVG images drawn from the same data.

How it is published #

A GitHub Actions workflow in the repository does the work. The unit tests run first, then the site is built and passes a leak gate (secrets, private network addresses, local file paths, e-mail addresses) before it may be published. The result is pushed to the public repository of this site (ta1rjv/bandplan) and served with GitHub Pages. Only the generated site is in the public repository; the source data repository is private.

What is not published #

Project status and planning files, raw source documents (PDF files, text dumps) and tool-specific configuration are not published. The sources page gives the official online link of every source.

Limitations #

  • The charts are static; there is no zoom and no class filter. Class access is given as a list on every band page.
  • Part of the English text has not been translated yet; those pages show the Turkish text.
  • The research documents are English only.
