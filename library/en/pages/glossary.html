This glossary explains general radio/engineering terms used on the site; the definitions below are general technical knowledge and are not attributed to a particular regulatory document. For this site's own terms such as class, allocation and confidence level, links to the relevant pages are given.

Band #

A frequency range with specific lower and upper frequency limits reserved for the amateur radio service (e.g. the 2 metre band: 144-146 MHz).

Segment #

A narrower sub-range within a band that is recommended or allocated for a specific use/mode (e.g. the CW segment of a band).

Allocation #

The official assignment of a frequency range by the relevant regulator to a particular radio service (e.g. the amateur service).

Emission type #

A short code describing the modulation/information-carrying form of the signal produced by a transmitter (e.g. A1A: keyed telegraphy/CW for aural reception). Detailed explanation: emission designators page.

Licence class (A/B/C) #

One of the three grades in which an amateur radio licence is issued in Turkey; each class has different band/power access. Details: licence classes page.

Repeater #

A fixed station that receives a signal on one frequency and retransmits it on another frequency, usually to cover a wider area.

Simplex #

A direct station-to-station mode of operation in which transmitter and receiver use the same frequency (no repeater is used).

EME (Earth-Moon-Earth) #

An operating mode in which communication between two ground stations is achieved by reflecting the signal off the surface of the Moon (moonbounce).

Amateur-satellite service #

The service category reserved for communication between amateur radio stations via amateur satellites in orbit.

PEP (Peak Envelope Power) #

The power value at the highest point of a transmitter's modulation envelope; a different measure from average output power.

e.i.r.p. (effective isotropically radiated power) #

The effective power an antenna system radiates in a given direction relative to an ideal (isotropic) antenna; a combined measure of transmitter output power and antenna gain.

Spot frequency #

A single frequency point within a band that is commonly used for a specific purpose (e.g. a calling channel, a centre of activity).

Channel plan #

A channel numbering system used on VHF/UHF FM bands, generated from a specific base frequency and step interval (e.g. V40, U280).

Verification/confidence level #

A label showing how clearly a data item is printed in the source document (Verified / Secondary source / Unverified). Details: IARU vs TR comparison page.
