# bandplan - Turkiye amateur radio band plan site

Read it at **https://ta1rjv.github.io/bandplan/** (Turkish by default, English selectable with the EN | TR switch).

A technical reference for the Turkish amateur radio band plan: for each of the 27 bands from LF/MF to EHF the BTK
legal allocation, the IARU Region 1 band plan, licence class access (A, B, C), spot frequencies and channel plans,
every value with a cited source and a confidence label, plus the research notes as a document library.

This repository only hosts the generated static site. It is built automatically from a private repository
(`ta1rjv/Turkiye-HAMBandPlan`) and published sanitized: a fail-closed leak check runs before every publication.

The content is informational and provided as is, without warranty of any kind. The binding text is the BTK
regulation; check the cited sources before relying on a value.
